# 0004 端侧小模型只负责理解，确定性的部分交给代码

状态：已采用

## 背景

路由要在离线时把一句中文拆成动作。规则路由的问题：
- 抓不住换了说法的句子
- 多个药只能识别出第一个

0.6B 模型能理解更多说法，但也有明显的毛病：
- 日期算错
- 照抄提示词里的示例（"老伴"）
- 把否定当肯定
- 复合句只给出一两个调用

## 决定

模型只回答两个问题："做哪几件事、提到了哪个药或症状"。其余由各平台共用的 `ModelPlan` 负责：
- 陈述句按分句分别问模型，再合并
- 日期从原话里计算
- 参数必须能在原话里找到，找不到就丢弃，不猜
- 否定（"还没吃"）不记录
- 提问优先交给药学 Agent
- 家属称谓从原话里读

模型不可用、超时（10 秒）或出错时，退回规则路由（`FallbackRouter`），保证离线时总能给出计划。

## 后果

- test 上整句完全正确率 87%（规则 48%），工具选择 91%（规则 58%）。详见 eval/routing/README.md。
- Mac CPU 上每句 p50 2.0 秒、p95 4.1 秒。手机上没有测过。
- 护栏代码是看了 dev 的错例写的，有对 dev 过拟合的风险，所以 test 只在最后跑一次。

## 放弃的方案

- **让模型直接输出完整参数（包括日期）**：日期换算错误率太高。
- **FunctionGemma 270M**：中文效果未验证，需要微调。Qwen3-0.6B 中文更好，下载也不需要登录。
