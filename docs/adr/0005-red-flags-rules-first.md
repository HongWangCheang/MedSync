# 0005 危险信号：规则先判断，模型只能补充

状态：已采用

## 背景

危险信号漏报的代价可能是一条命，误报的代价是多看一眼提示。同时，医疗场景要求每条提醒都说得清理由。

关键词规则可解释、零延迟，但换个说法就抓不到。test 上召回率只有 31%，例如"心口像压了块大石头，还出冷汗"一个关键词都没有。

## 决定

- **规则先判断**：命中就立刻提醒，不等模型。
- **规则没命中时，再问端侧模型**：模型只能**增加**提醒，不能撤销规则的提醒。
- **模型必须照抄原话里说明危险的几个字作为依据**。以下情况都不提醒：
  - 依据在原话里找不到
  - 依据被否定（"没有……"）
  - 依据是口头禅（"累死了""要我命"）
- **界面区分来源**：模型判断的提醒写"可能是危险信号"，并注明来自本机模型。
- **只建议就医或求助，不做诊断**。急症提示拨打 120，心理危机提示 12356 热线。

## 后果

- test 上召回率 31% → 92%，误报率 23% → 36%。按"宁可多提醒"取舍，误报率照实报告。
- 心理危机有时被模型归成急症：用户仍会看到拨打 120 的提示，但看不到热线（test 上 3/6 给出了热线）。
- 规则没命中时，提醒要多等 1–3 秒。规则命中的句子不受影响。
