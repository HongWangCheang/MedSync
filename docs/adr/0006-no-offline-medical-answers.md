# 0006 离线时不回答用药问题

状态：已采用

## 背景

设备上有一个能理解中文的模型，"离线也能回答用药问题"看起来很自然。但 0.6B 模型没有说明书可以检索，答案无法核对，用药问题答错的代价很高。

## 决定

- 用药问答只在联网时由云端药学 Agent 回答：检索 openFDA 说明书，答案带 [S1] 这样的引用，点开能看到原文；找不到可引用的原文就拒答。
- 离线时，这个问题不进入队列，直接提示"需要联网"。
- 界面的离线能力面板把它标为"需要联网"。

## 后果

- 离线时用户问用药问题得不到回答，但不会得到一个没有依据的回答。
- 不进队列是因为问题有时效性：联网后自动弹出一个过时的回答，不如让用户自己重新问。
