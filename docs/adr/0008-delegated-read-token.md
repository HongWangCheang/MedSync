# 0008 药学 Agent 用委托令牌读用药清单

状态：已采用

## 背景

用户问"我吃的药能一起吃吗"时，药学 Agent 需要读用户记录过的用药。但 Agent 服务不应该长期持有用户的访问凭证；而且 LangGraph 会把状态写进 checkpoint，凭证一旦写进去就会长期留在数据库里。

## 决定

- 网关只给需要的两个步骤（用药问答、记录服药）签发委托令牌：只读用药清单、2 分钟有效。
- 令牌随请求传给 Agent，不写进 LangGraph 的状态和 checkpoint。
- 每次派发都重新签发：例如安全审核服务暂时连不上、动作过一会儿被重派时，拿到的是一个新令牌，不复用旧的。

## 后果

- 冒烟测试检查过：checkpoint 里从来没有出现过令牌。
- Agent 服务被攻破时，拿到的只是短期、只读、范围很小的令牌。
