# 2 分钟演示

一段带讲解的录屏，展示 MedSync 解决的问题。下面的动图是同一个故事，没有声音，由 `DemoTest` 在真实的 App 和服务上自动跑出来，每一步都有断言。

![演示](demo.gif)

## 准备（录之前）

```sh
scripts/up.sh --model                 # 启动服务、跑冒烟测试、准备端侧模型
curl -X POST 127.0.0.1:9100/admin/reset
cd client && ./gradlew :desktopApp:run
```

另开一个终端，准备好"抢号"命令（日期换成明天）：

```sh
curl -X POST 127.0.0.1:9100/admin/slots/YYYY-MM-DD -H 'Content-Type: application/json' -d '{"available": 0}'
```

窗口启动约 7 秒后模型才加载好，等标题下面那行出现再开始录。

## 分镜和讲解

| 时间 | 画面 / 操作 | 讲解要点 |
|---|---|---|
| 0:00–0:15 | 打开 App，指一下顶部那一行 | "MedSync 是一个用药助手，要解决的是：网络不稳定时，Agent 去预约、发消息这类有副作用的操作，既不能重复执行，也不能执行已经过时的。" |
| 0:15–0:30 | 输入"我吃了华法林"，出现安全审核结果 | "在线时，服药记录同步到服务器，安全审核 Agent 会对照最近 7 天的用药。现在只有一种药，没有可以对照的。" |
| 0:30–0:45 | 打开"模拟离线"开关，面板展开 | "断网后，界面标出每项功能离线时怎么办：哪些在本机完成，哪些排队等联网，用药问答直接拒答，因为离线时没有说明书可以引用。" |
| 0:45–1:00 | 输入"胸口像被人攥住一样，出了一身冷汗"，出现红色提醒 | "危险信号在本机判断。这句话里没有'胸痛'这类关键词，规则抓不到；本机的 0.6B 模型补充判断，还要指出是原话里的哪几个字，所以提醒可以解释。" |
| 1:00–1:15 | 输入"我吃了布洛芬，告诉女儿我没事，帮我约明天的心内科" | "还是断网。本机模型把一句话拆成 3 个动作，通知要等服药记录处理完。每个动作在这时就生成了 step_key，存在本机。" |
| 1:15–1:20 | 在终端执行抢号命令 | "离线期间，明天的号被别人抢光了。" |
| 1:20–1:40 | 关掉离线开关，等两张卡片变成"需要你确认" | "联网后，安全审核发现布洛芬和华法林有出血风险。排队的'我没事'和这个结论矛盾，被暂停；预约发现号没了，问我改约哪天。" |
| 1:40–1:55 | 点"附上提醒再发"、点"改约" | "我确认之后才执行：消息附上服务器生成的提醒发出去，预约改到后天。" |
| 1:55–2:00 | 终端 `curl 127.0.0.1:9100/metrics/side_effects` | "外部系统自己记的数：预约 1 次、通知 1 次。在 640 个故障注入回合里，重复执行率是 0%，朴素重试是 50%。" |

## 想多讲一点时

- **为什么每个动作都带 step_key**：断网重试、网关重派、LLM 重新推理，用的都是同一个键，三跳都按它去重（[ADR 0001](adr/0001-step-key-across-three-hops.md)）。
- **"已提交、响应丢失"怎么办**：先写 INTENT，结果不明时先去外部系统查（[ADR 0002](adr/0002-intent-committed-ledger.md)）。演示里可以用 `chaos/` 下的脚本注入这个故障。
- **为什么离线不回答用药问题**：见 [ADR 0006](adr/0006-no-offline-medical-answers.md)。
